Comparación A/B · iPhone Safari

Lock vs Pattern refraction

Qué es Pattern refraction (Figma): un shader WGSL que dobla la imagen como si miraras a través de lentes de vidrio texturizado (Lenticular, Waves, etc.), con Strength, Smoothness, Frost, Dispersion y Edge wrap. Nuestro Lock: material frosted con backdrop-filter (blur + saturate + tinte + borde) — no refracta ni desplaza píxeles. Panel B es una emulación web del shader Figma «Pattern refraction»: no es Glass nativo de Figma, ni pixel-perfect del WGSL.

Panel A

Glass Lab Lock

Defaults del material: opacity 0.15, blur 10px, saturate 1.15, brightness 1.10, contrast 1.05, border 0.25px @ 0.35, specular 0, noise 0.12, radius 20, inner 0.20, outer 0.

Pattern refraction

Emulación web · shader Figma «Pattern refraction» · no nativo · no pixel-perfect

Controles en vivo

Límites honestos

Esto emula Liquid Glass en la web con backdrop-filter (+ -webkit-backdrop-filter), tinte, borde, especular, noise y sombras. No es el material de sistema Liquid Glass de iOS 26 / visionOS: no hay lente real del compositor OS ni el mismo muestreo de capas detrás del chrome.

  • Safari iOS/iPadOS soporta backdrop-filter; el rendimiento baja si el blur es muy alto.
  • El material Lock no tiene distorsión ni aberración: stack profesional (blur + color + borde + luz).
  • La sección A/B añade Panel B (aprox. Pattern refraction): crestas CSS + frost blur + fringe leve — no es el shader WGSL de Figma ni Glass nativo.
  • Si backdrop-filter no está disponible, el material sigue usable (tinte + borde + sombra).
